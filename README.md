## Project Description

This project is a simple web server application created using Node.js and Express.js.

The application displays my name, course code (WEB322), and the current GMT date and time.

The GMT date and time are generated dynamically using the JavaScript `new Date().toISOString()` method.

## Technologies Used

- Node.js
- Express.js
- JavaScript
- GitHub
- Vercel

## How to Run the Application

1. Download the project files.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Install the required dependencies:

   `npm install`

5. Start the server:

   `npm start`

6. Open the following URL in a browser:

   http://localhost:3000

## Expected Output

Muhammad Bajwa - WEB322

The current GMT date and time will appear below my name.
